# UseSkillPatch — плагин для CS2

Плагин для CounterStrikeSharp, который позволяет использовать способности из jRandomSkills по нажатию клавиши E.

## Особенности
- Активация скилла через кнопку Use (E)
- Защита от многократного срабатывания (debounce 300 мс)
- Автоматическая очистка данных игроков при отключении
- Работает только с живыми игроками в командах

## Требования
- [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp/releases)
- [jRandomSkills](https://github.com/Juzlus/jRandomSkills)

## Установка
1. Скачайте последнюю версию плагина
2. Распакуйте и поместите папку `UseSkillPatch` в: 
```
/game/csgo/addons/counterstrikesharp/configs/plugins/
```
